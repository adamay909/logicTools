To enable editing, click on the input area. If input is active, the frame will turn blue and the cursor starts blinking.

Click on name of logical system to switch between Sentential and Predicate Logic.

You can edit the title by clicking on the blue bar at the top.

Using a physical keyboard is strongly recommended.

The turnstile symbol and the dots separating the annotation from the sequent are provided automatically and cannot be deleted.

How to input logical symbols:

  • ¬ :   - (the minus sign)
  • ∧ :   ^ (shift-6 on US keyboard)
  • ∨ :   v (alphabet letter v--lower case)
  • ⊃ :   > (greater than symbol)
  • ⊢ :   | followed by - (vertical line--shift-backslash on US keyboards--followed by the minus sign)
  • Γ :   \ followed by G (backslash--usually right above the Enter key--followed by G)
  • Δ :   \ followed by D
  • Θ :   \ followed by T
  • You can get a lot of other Greek letters by typing \ and following it by some letter of the Roman alphabet (both upper and lower case). Try it!
  • brackets:   the editor accepts only one type of brackets--the ordinary parentheses.
  • ∀ :   U
  • ∃ :   X
  • ≠ :   \ followed by =

The following letters cannot be used for sentence, predicate, and term letters: v, U, and X.

In the title area, you can use |v, |U, |X, |> to input lowercase v, uppercase U, uppercase X, >.

The editor will format your derivation on the fly. It is not possible to control the formatting.

Inference rules must be specified by abbreviations used in the course material (see ).

Theorems and Axioms must be specified by abbreviations used in the course material (see ).

You can add subscripts by typing _ (underscore) followed by a single character (WARNING: the use of subscripts is experimental and might produce unexpected errors).
